Политика обработки персональных данных

Настоящая политика описывает обработку персональных данных посетителей сайта marselgaleev.ru. Оператор — индивидуальный предприниматель Галеев Марсель Рафаэлевич. Контакт для обращений: mars@rois15.ru.

Какие данные мы получаем

При обращении через форму посетитель указывает имя и фамилию, номер телефона, при желании — имя пользователя Telegram, адрес сайта компании, а также описание проекта или ответы на вопросы брифа. Вместе с обращением могут передаваться выбранная услуга, адрес страницы сайта и UTM-метки источника обращения. Просим не включать в описание сведения, которые не относятся к задаче, и специальные категории персональных данных.

При посещении сайта технические сервисы могут получать IP-адрес, сведения о браузере и устройстве, запрашиваемых страницах и файлах cookie, необходимые для работы и защиты сайта. Сайт размещён на GitHub Pages. Для анализа посещаемости и работы сайта используется Яндекс Метрика, включая Вебвизор; содержимое полей заявок и калькулятора скрыто от записи Вебвизора.

Зачем обрабатываются данные

Данные обращения используются, чтобы рассмотреть запрос, связаться с посетителем и обсудить возможное сотрудничество. Основание — согласие, выраженное самостоятельной установкой отметки и отправкой формы, а также иные основания, предусмотренные законодательством, если они применимы. Для рекламных рассылок данные обращения без отдельного основания не используются.

Как обрабатываются и передаются данные

Оператор может получать, записывать, хранить, уточнять, использовать, передавать в объёме, необходимом для доставки обращения, и удалять данные. Для работы формы используются сервер OneDash и Telegram-бот; уведомление о заявке направляется оператору через Telegram. В обработке технически могут участвовать поставщики хостинга и связи, а также сервисы Telegram и Livegram. Инфраструктура отдельных сервисов может находиться за пределами Российской Федерации, в связи с чем передача может быть трансграничной.

Доступ к настройкам обработки ограничивается; для передачи данных используется защищённое соединение. Данные хранятся в течение времени, необходимого для рассмотрения обращения и достижения целей обработки, либо дольше, если это требуется законом или есть другое законное основание.

Права посетителя

Чтобы получить информацию об обработке, уточнить данные, потребовать их удаления или отозвать согласие, напишите на mars@rois15.ru. Отзыв согласия не исключает обработку при наличии другого предусмотренного законом основания.

Изменения политики

Актуальная версия политики размещается на этой странице. При изменении способов обработки данные положения пересматриваются.
